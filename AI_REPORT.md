# Заметки о разработке

При разработке использовался Codex. Приложение выполняет анализ с помощью детерминированных правил в браузере.

При разборе отрицательных сумм исправлено сохранение знака и добавлена проверка неположительного значения. Для реквизитов договора ограничено чтение номера одной строкой, чтобы номер следующего пункта не принимался за номер договора.

Валидатор отдельно сверяет выводы с исходным текстом. Некоторые функции обработки реквизитов и дат общие с парсером, поэтому в этих случаях возможны совпадающие ошибки.
